This is the single consolidated requirements specification. The main body merges the supported recorded pitch content with current website defaults, vehicle allocations, subsystems and software requirements. Appendix A retains the pitch reconciliation; Appendix B preserves the source crosswalk. Appendices provide traceability and do not create a competing requirements baseline.

Working design requirements based on current website defaults and user instructions; no formal approval inferred. Original 91 source requirements remain archived. Current allocation governs this draft where differences are listed.

Presentation provenance: Recorded extracted phase map only; original slide deck not available in this workspace or located in connected Drive. Latest pitch revision not independently verified.

The recorded deck is FREYA_Pitch_Expanded_Science_Three_Categories.pptx, 10 slides. Its slide 7 delivery order and slides 3–4 science alternatives are retained via the existing phase map. Original slide wording, figures and latest revision cannot be verified without the deck.

Terminology: capsule = entry aeroshell/heat shield/cover; carrier = extracted platform retaining and releasing probes; probe = independent impact/science node; reentry module = detachable retro propulsion and cold-gas assembly. A software function may execute on shared retained avionics; allocation does not imply a separate processor.

All requirements below are proposed working requirements with verification open. Numeric defaults are identified as design allocations, references or analysis assumptions. No approval, hardware qualification, life-detection sensitivity or mission probability is inferred. A shall statement defines intended acceptance, not demonstrated capability.
