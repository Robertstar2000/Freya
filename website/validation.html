Calculation and data audit

17 November 2026 · Software verification and source traceability. Numerical checks do not validate unmeasured hardware or Mars material properties. Visual and interactive browser QA could not be performed in this environment.

Data flowVariablesEquationsSourcesFindings and verification limits

How the data connects

  1. Rev09 defines A/B mission references. Configuration selection restores the 400 km initial trade; A uses 2,000 N·s, 100 N and 0.1 kg initial nitrogen.
  2. A propulsion allocation is dry module + impulse/(Isp g₀) + ideal-gas nitrogen. Remaining allocations scale together; probe mass is derived from the shared probe allocation divided by count. B allocation rows remain a fixed reference; edited wet/probe masses require reallocation.
  3. The cold-gas budget covers separation, retroburn alignment (90° default), and post-burn heat-shield alignment (180° default). Wet mass minus only pre-burn gas feeds the finite burn; entry-alignment gas stays aboard until after cutoff. Module jettison occurs five seconds after that turn. Propellant, dry module and residual gas are removed once to obtain entry mass. Entry state seeds carrier descent. Each probe inherits its release position and velocity; carrier mass drops by that probe mass.
  4. Atmospheric density and scale height feed entry and chute drag. Main engineering density, jet thrust, lever arm, inertia and planning allowance feed the flight model. Screening PCM suspended mass affects only the constant-density terminal-speed card.
  5. Calculated descent velocity and current probe mass feed the Poncelet soil screen. Ground telemetry shows zero current speed while retaining pre-impact velocity separately.
  6. The two review sliders inspect the same calculated solution with different time compression. Event bits are scripted confirmations. Science labels and relay animations do not generate measurements or prove reception.
  7. The 91-item evidence register uses separately recorded 300 km / 1,280 N·s A baseline runs. Current slider trades never update historical evidence or downloadable reports automatically.

Findings and verification limits

  • Corrected unreachable-latitude target acceptance, stale flight displays after errors, and ground current-speed labeling.
  • Added mass/domain guards and independent identities for radio loss, drag, energy, orbital speed, staged mass accounting and numerical penetration integration; current A trajectory is checked at half integration steps.
  • Input editing now stays in the control; explicit Calculation buttons open explanations. Reconciled outdated motor labels and B source allocations against current trades.
  • A paired-jet flight budget and the single-jet engineering screen use deliberately different torque definitions. The inspector explains both.
  • Reduced orbital-plane targeting, exponential atmosphere, imposed stable attitude, approximate heating, nonablating TPS and uncalibrated soils remain design assumptions. Neither successful arithmetic nor heritage constitutes FREYA qualification.
  • External citations justify equation context, not assumed parameter values. Internal source files require account access; historical reports preserve older inputs and are not live exports. Spacek et al. IMPRESS abstract, author preprint sections 3.1–3.2.1, and supplementary Table S1 were reviewed on 17 November 2026; the live penetration panel now shows their numeric reference values and evidence status. Those aggregate ranges do not calibrate the three soil curves. Other external references were not independently reauthenticated in this audit.
  • Reproduce: npm test, node scripts/build-requirement-evidence.mjs, npm run build. Recorded test results. Visual browser testing remains outstanding.

Computation and output dictionary

Orbit and deorbit sizing

ra = R + 1000 h₀; rp = R + 1000 hp; a = (ra + rp)/2
v_c = √(μ/ra); v_transfer = √[μ(2/ra − 1/a)]
Δv = v_c − v_transfer

μ = 4.2828 × 10¹³ m³/s²; R = 3,389,500 m; altitude inputs in km.

Two-body vacuum sizing. Periapsis is a sizing proxy, not an atmospheric landing target.

Variables: m.orbitKm, m.periapsisKm. Implementation

Delta-v planning allowance

Δv_design = Δv × (1 + marginPct/100)
Momentum-equivalent demand = m_wet × Δv_design
Propellant allowance = m_burn [1 − exp(−Δv_design/(Isp g₀))]

g₀ = 9.80665 m/s².

Momentum-equivalent demand is not delivered motor impulse. Flight propellant uses burn mass after conservative cold-gas use. Allowance is not added to the nominal commanded burn.

Variables: m.orbitKm, m.periapsisKm, m.marginPct, m.wetKg, f.Aisp, f.Bisp. Implementation

Mass and geometry

m_probes = N × m_probe; m_other = m_wet − N m_probe
m_mission = vehicles × m_wet
A_shell = π D_shell²/4; β = m_wet/(1.5 A_shell)
m_entry = m_after_burn − entry_alignment_gas − m_module_dry − gas_remaining_at_jettison
A current trade: m_propulsion = m_module_dry + impulse/(Isp g₀) + P V/(R_N₂ T)
scale = (m_wet − m_propulsion)/17.5; other allocations = source allocation × scale
m_probe = 6 scale/N; m_carrier_dry = 3 scale

Screening ballistic coefficient uses Cd = 1.5. Flight Cd is separately editable.

Provisional total height = 0.75D assumed backshell + (D/2)tan20° forebody cone envelope. NASA 70° is measured from the symmetry axis, equivalent to 20° from the shield plane. Nose/shoulder blends require CAD; backshell slope is independent. Height is a derived packaging envelope; it does not enter the current drag, inertia or volume solver. Mass and diameter affect subsequent propagation; inertia is an independent assumption.

Variables: m.wetKg, m.count, m.probeKg, m.vehicles, m.diameterM, m.heightM, f.moduleDryA, f.moduleDryB, f.AimpulseNs, f.Aisp, f.tankBar, f.tankLitres, f.tankKelvin. Implementation

Constant-density terminal-speed screen

A = π D²/4
v_terminal = √[2 m × 3.71/(ρ Cd A)]

Screening gravity = 3.71 m/s². Fully inflated canopy; constant input density.

Probe uses complete probe mass and probe canopy. PCM screen uses suspendedKg. The time-resolved carrier instead uses retained dry mass plus unreleased probes; suspendedKg does not set that mass.

Variables: m.probeKg, m.probeChuteM, m.suspendedKg, m.pcmChuteM, m.rho, m.cd. Implementation

Radio link and transmit energy

FSPL_dB = 32.44 + 20 log₁₀(f_MHz) + 20 log₁₀(range_km)
P_rx = 10 log₁₀(1000 P_RF) + G_tx + G_rx − FSPL − losses
Link margin = P_rx − receiver threshold
P_DC = P_RF/η; E_1h = P_DC × burst_seconds/period_seconds

MHz/km convention gives 32.44 dB constant. 1000 converts W to mW.

Illustrative free-space budget; reception, relay access, antenna attitude, framing and acquisition costs remain unverified. E_1h is Wh for one hour at the specified duty cycle.

Probe surface energy

E_load [Wh] = P_average [W] × operation_hours [h]
E_remaining = E_usable − E_load

1 Wh = 3600 J.

Usable energy and average power are assumptions. This screen does not predict temperature derating, science duty-cycle details or battery qualification.

Variables: m.energyWh, m.averageW, m.operationHours. Implementation

Single-jet attitude screening

τ = F_jet × lever; α = τ/I
t_90 = 2 √[(π/2)/α]
m_gas = F_jet × cumulative_jet_seconds/(Isp g₀)

g₀ = 9.80665 m/s²; angle = π/2 rad.

Engineering screen uses one-jet torque. Calculated flight uses opposed pairs and a separate pulse allowance; inspect paired-jet flight equations below.

Variables: m.inertia, m.jetN, m.leverM, m.jetSeconds, m.ispSec. Implementation

Paired-jet separation and alignment

F_sep = 2 F_jet; t_sep = m_wet Δv_sep/F_sep
x_pulse = ½ Δv_sep t_sep; t_coast = max[0,(clearance − x_pulse)/Δv_sep]
τ_pair = 2 F_jet lever; α = τ_pair/I; t_slew = 2 √(θ/α)
m_sep = m_wet Δv_sep/(Isp_jet g₀) × (1 + pulse_margin/100)
m_slew = 2 F_jet t_slew/(Isp_jet g₀) × (1 + pulse_margin/100)

g₀ = 9.80665 m/s²; two balanced jets; degrees converted to radians.

Three maneuver budget: separation translation, retroburn alignment, and a separate heat-shield alignment after cutoff before module jettison. The two slews each use t=2 sqrt(angle/alpha), m=2 F t/(Isp g0) times pulse allowance; default angles 90 and 180 degrees. Rest-to-rest bang-bang slew. Conservative pulse allowance changes budgeted gas, not nominal maneuver duration. Assumed inertia is independent of the geometry sliders.

Variables: m.wetKg, m.jetN, m.leverM, m.inertia, f.inertiaA, f.inertiaB, f.separationDv, f.separationClearanceM, f.slewDeg, f.heatSlewDeg, f.jetIsp, f.gasMarginPct. Implementation

Nitrogen storage and consumption

m_initial = P_bar × 10⁵ × (V_L/1000)/(R_N₂ T)
m_unavailable = P_min × 10⁵ × (V_L/1000)/(R_N₂ T)
m_remaining = m_initial − m_separation − m_retro_alignment − m_entry_alignment − leakage
P_remaining,bar = m_remaining R_N₂ T/(V_L/1000)/10⁵

R_N₂ = 296.8 J/(kg K); 10⁵ Pa/bar; 1000 L/m³.

Ideal gas. Minimum-pressure residual is unavailable. No real-gas compressibility, regulator/plumbing loss or blowdown cooling. Budgeted conservative maneuver masses include the pulse allowance.

Finite main-engine burn and propellant

m_burn = m_wet − budgeted separation/retroburn-alignment gas (entry alignment gas remains aboard)
m_prop = m_burn [1 − exp(−Δv_required/(Isp g₀))]
A: t_burn = fixed impulse/fixed thrust; mass flow = thrust/(Isp g₀)
B: thrust = m_prop Isp g₀/t_burn
m_fuel = m_prop/(1+O/F); m_oxidizer = m_prop O/F/(1+O/F)
dr/dt = v; dv/dt = −μ r/|r|³ − (thrust/m) v/|v|; dm/dt = −thrust/(Isp g₀)

μ = 4.2828 × 10¹³ m³/s²; g₀ = 9.80665 m/s²; RK4 burn step = 0.05 s.

A uses its entire fixed impulse, no cutoff at nominal Δv. B is sized at assumed Isp and mixture ratio. Fuel/oxidizer split applies only to B. Flight includes gravity and changing mass.

T_orbit = 2π √[(R + 1000 h₀)³/μ]
Search orbital phase over minOrbits…maxOrbits

Ground miss = R × great-circle angle(predicted landing, target)

Includes propagated entry/coast and first probe descent displacement. Uses an assumed plane and epoch. Reports closest miss and reachability; does not guarantee a hit.

Entry altitude, speed and capsule load

h = r − R; ρ(h) = ρ₀ exp[−max(0,h)/H]
v_air = hypot(v_r, v_t − Ω cos(i) r); q_dynamic = ½ ρ v_air²
A = π D_shell²/4; drag acceleration = q_dynamic Cd A/m_entry
dr/dt = v_r; dθ/dt = v_t/r
dv_r/dt = v_t²/r − μ/r² − a_drag v_r/v_air
dv_t/dt = −v_r v_t/r − a_drag (v_t−Ω cos(i)r)/v_air
v_inertial = hypot(v_r,v_t); proper load = a_drag/g₀

R = 3,389,500 m; μ = 4.2828 × 10¹³ m³/s²; Ω = 2π/88642.6848 rad/s; g₀ = 9.80665 m/s²; interface = 125000 m.

Spherical zero-lift RK4 model. Before ignition capsule speed is circular-orbit speed; burn/coast use Cartesian propagation. Proper load is thrust/(m g₀) during burn and zero during orbital free fall. Discard ends capsule trajectory.

Center and shoulder surface temperatures

q_center = 1.9027×10⁻⁴ √(ρ/R_nose) v_air³
q_shoulder = q_center × shoulderFlowFactor × √(R_nose/R_shoulder)
C_surface = ρ_TPS Cp × surfaceLayer; C_bulk = ρ_TPS Cp × (L−surfaceLayer)

Carrier and probe chute descent

ρ = ρ₀ exp[−max(0,h)/H]; v_rel = hypot(v_x−wind, v_y)
CdA_carrier = 0.4×0.12 + Cd_chute π D_carrier²/4 × inflation
CdA_probe = 0.45 π(0.05)²/4 + Cd_chute π D_probe_chute²/4 × inflation

dv_x/dt = −k_drag(v_x−wind); dv_y/dt = −μ/(R+h)² − k_drag v_y
Speed = hypot(v_x,v_y); drag load = ½ ρ v_rel² CdA/(m g₀)

μ = 4.2828 × 10¹³ m³/s²; R = 3,389,500 m; g₀ = 9.80665 m/s²; carrier body CdA = 0.048 m²; probe body diameter = 0.05 m and body Cd = 0.45.

Carrier inflation ramps linearly after 1 s. Probe inflation ramps after its release plus probeDelaySec. Release cadence follows first altitude gate. Shared physical clock and inherited release state; ground is linearly interpolated to h=0. Current speed reads zero after landing; impact speed is retained separately.

Ground impact deceleration and penetration

v_normal = |v_vertical| cos(obliquity); A = π D_impact²/4
a = A R_bearing; b = ½ ρ_material Cd_inertial A
F(v) = a + b v²
z = m/(2b) ln(1 + b v_normal²/a)
g_peak = (a + b v_normal²)/(m g₀); g_mean = v_normal²/(2 z g₀)
t_stop = m/√(ab) atan[v_normal √(b/a)]
For b=0: z=m v_normal²/(2a), t_stop=m v_normal/a
Zero velocity → zero impact outputs; warn if z > probe length

g₀ = 9.80665 m/s²; 10⁶ Pa/MPa.

Spacek et al. (2026) published reference depths are shown separately in the penetration panel; their mission ranges are not matched shot records and do not calibrate the Poncelet coefficients. Poncelet point-mass screen. All three resistance/density/inertial coefficient sets are uncalibrated assumptions. Bearing resistance is not UCS. During descent this is a current-speed what-if; after ground it uses pre-impact downward velocity. Depth shading uses independent assumed lognormal factors: R 1.35, density 1.10, Cd 1.25, mass 1.05 and diameter 1.03 at 1σ. Local log-linear propagation gives depth × exp(±3σ_log_depth); approximate central 99.73% only under those assumptions. Speed/tilt fixed; no model discrepancy included. Full derivation is beside the chart and implemented in penetration-uncertainty.mjs. No crush, fracture, rebound or instrument shock/survival model. Probe length only triggers an extrapolation warning.

Main mission review time

Review fraction = (playback_time − phase_start)/(phase_end − phase_start)
Coast time = moduleDetached + coast_fraction × (entryStart − moduleDetached)
Entry time = entryStart + fraction × entryDuration
Release/delivery time interpolates between the calculated extraction, release and impact boundaries
A dedicated 60-second review segment covers the full post-jettison coast to entry; orbit waiting intervals are compressed by review phase

Review durations are presentation timing, not physical seconds.

All probe descents use one common physical time. Event focus/status confirmation is scripted. Science/incubation remains illustrative. The slider changes playback position only.

Physical flight review time

p = min(7, slider_value/1000 × 7); i = min(6, floor(p))
t = knot[i] + (knot[i+1]−knot[i]) × (p−i)
Knots = [0, separationEnd, alignStart, burnStart, burnEnd, entryStart, descentStart, missionFlightEnd]

All physical knot values are computed from the current flight solution.

Seven equal slider intervals compress unequal real durations. This slider affects inspection time, not flight dynamics.
