# FREYA Sites Version — 3D Mission Simulator

## Key updates
- Improved 3D-style visualization with perspective, shading, orbit geometry, release cloud, tethered surface package, and buried science probe.
- Numeric displays include penetration depth, science package mass, impact spread, mission phase, impact velocity, power duration, communications margin, and planetary-protection status.
- All mission parameters are manually adjustable and visible in the control sidebar.
- Mission phase table and live telemetry are populated from the current scenario and update during playback.
- Legacy Sites assumptions for geometry, tether, potting, thermal attenuation, communications margins, and planetary-protection process trade are now active controls.
